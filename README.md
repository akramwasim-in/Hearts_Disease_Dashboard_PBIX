# Heart Disease Dashboard (Power BI)

This is a Power BI dashboard project.

In this project, heart disease data is analyzed using Power BI.
The dashboard shows total patients, heart disease percentage, average age,
and comparison based on gender, age group, smoking, and diabetes.

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- CSV file

## Files
- heart_disease.csv (Source data)
- Heart_Disease_Dashboard.pbix (Power BI file)
- Dashboard_Screenshot.png

## How to Open
1. Download the project
2. Open the .pbix file in Power BI Desktop
3. Use slicers to filter data
